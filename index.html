Why we stopped instead of publishing a TIFF

  • The concealment candidate was below its count- and distance-profile-matched random control on the same component holdout.
  • Its holdout is a proxy built from withheld catalogue components; those components do not equal the competition's hidden expert-labelled faults.
  • The nine requested sibling projects' registered raster bytes could not all be retrieved for the correlation/3-pixel overlap audit after GitHub API rate-limit HTTP 403. The duplicate gate is therefore not passed.
  • The D2.8 and H33-2-B2 TIFFs remain useful for learning and audit only; copying, re-encoding, or slightly perturbing either is not a new scientific submission.

When a candidate clears the frozen holdout and uniqueness gates, its one-click download will appear here with an explicit OK TO SUBMIT label, matching sidecar SHA-256, a unique filename, and a note of at most 140 characters. A local format check will never be described as organizer acceptance.
