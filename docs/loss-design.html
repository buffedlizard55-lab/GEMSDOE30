Training objective · synthetic validation only

Make the loss see 300 metres.

The competition scores a distance-tolerant raster. The training objective now has both an exact-pixel regional term and a geometry term that uses the official triangular kernel.

Regional term

Soft Tversky

Lreg = 1 - (TPpixel + eps) / (TPpixel + 0.2 FPpixel + 0.8 FNpixel + eps)

Retains exact region information and an explicit false-negative emphasis.

Geometry term

Distance-weighted Tversky

Lgeom = 1 - DTI300m with k(d) = max(1 - d / 300m, 0). False-positive costs use an EDT to the nearest target; per-truth credit takes the best local weighted probability.

Initial paired experiment

Combined, not substituted

L = 1.0 × Lregional + 0.5 × Lgeometry

The 0.5 geometry coefficient is a starting ablation setting, not a tuned optimum. Change its value only under a frozen spatial protocol; do not use the public leaderboard to choose it.

What passed

Toy geometry test

The dependency-free probe confirms that regional exact-overlap loss ties non-overlapping shifts while the metric term prefers a 100 m miss to a 200 m or farther miss. A disposable 64×64 synthetic smoke also passed the paired four-fold plumbing through GeoTIFF validation. These verify software only—not geology, a real holdout, or score improvement.

PYTHONPATH=src python scripts/loss_geometry_probe.py

What did not pass yet

No real holdout result exists

Training data, labels, and template are missing. No model was trained, no held-out fault was scored, and no reduction in real near-misses or leaderboard gain is claimed. Real spatial validation is still required.
