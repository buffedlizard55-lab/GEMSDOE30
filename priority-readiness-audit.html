What does H33-B2 establish?

The archived byte audit found H33-B2 is an earlier 40,199-dot r1 raster with 2,545 dots near the mapped-fault halo removed, leaving 37,654 dots. GEMSDOE36 adds 1,200 dots to H33-B2; GEMSDOE25 and GEMSDOE30 have identical in-footprint values despite different file hashes. These are file-lineage findings, not independent geological discoveries or causal proof of score improvement.

The reported 0.2778 is not an organizer-confirmed receipt here. Pruning could reduce false-positive cost while retaining distance-kernel coverage, but the hidden TP/FP changes are unknown. No defensible estimate establishes that a new method will exceed it. Archived lineage evidence.

Reproduce without a human inspector

python scripts/audit_priority_readiness.py --restore
python scripts/audit_priority_readiness.py --check

Restore the pinned template and lattice first using the README commands. Check mode performs no network access. Hashes, integer counts, verdicts and generated HTML must match exactly; floating-point diagnostics use the shared verifier's 1e-12 tolerance for numerical roundoff. Neither successful execution nor a format PASS selects a slot. There is no leaderboard estimate, no new HOLDOUT-DTI result, and no ORGANIZER-CONFIRMED score in this audit.
