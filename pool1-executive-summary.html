Why did GEMSDOE32's 0.2778 happen — and can we beat it?

Re-verified pixel-exactly today: H33-B2 is the 44,090-dot D2.8 cloud minus exactly the dots at ≤2 px from mapped faults (3,891 at 1.0 px, then 2,545 at 1.41–2.0 px). The organizer masks only the catalogue pixels themselves, so those halo dots were paid false positives earning no extra kernel credit. The whole 0.2600 → 0.2708 → 0.2778 ladder is denominator hygiene at constant truth credit — zero new geology, and the pruning ceiling is now exhausted. Beating 0.2778 (let alone today's live #1, 0.4544) requires recall of hidden faults (misses cost 4× false positives: β=0.8 vs α=0.2). POOL-1 is the first mechanism here to measurably raise concealed-fault recovery (+0.040 in the SE Walker Lane fold); converting it into a submittable file is now an emission-placement problem, specified as POOL-2 in the full review §7.
