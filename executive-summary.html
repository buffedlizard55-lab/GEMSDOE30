Protocol before any slot

Submission gates (must all pass)

  1. Obtain the organizer template through the authorized competition data page.
  2. Generate a new single-band GeoTIFF on the template grid using gemsdoe30.submission.write_submission_file; never rename or perturb a stopped raster.
  3. Run python scripts/validate_submission.py FILE.tif --template data/raw/sample_submission.tif. Local format pass ≠ portal acceptance, novelty, or scientific merit.
  4. Compute HOLDEOUT-DTI on a buffered spatial holdout with fresh-seed confirmation; beat the same-protocol best with CI lower bound > 0.
  5. Check novelty against the complete current registry (surface ρ ≤ 0.90 AND dot overlap ≤ 70% within 3 px).
  6. Obtain separate selector approval within the weekly cap (3 feedback submissions/week). Use the unique run name and note ≤ 140 characters.
  7. On the competition site, select the TIFF under File to submit, enter the note, create the submission.

Previous portal error: "Predicted values must be in range [0, 1]" — cause not established. The local check requires finite values inside the footprint and null outside; do not infer it reproduces the organizer's validator.
