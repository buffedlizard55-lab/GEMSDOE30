File contract

Before you upload

  • One GeoTIFF band; data type float32.
  • Projected CRS matches the provided grid: UTM zone 11N, EPSG:32611.
  • 100 m pixels and the exact template shape, bounds, and geotransform.
  • Every in-footprint value is finite and in the closed interval [0, 1].
  • Pixels outside the valid template footprint are null/NaN (the project's writer uses NaN and a NaN nodata tag).
  • Use the organizer-provided sample template; never invent the footprint or infer the grid from a screenshot.

These requirements are taken from the official competition problem description. The local validator checks them against the downloaded template but cannot guarantee portal acceptance.

Range-error fix

“Predicted values must be in range [0, 1]”

The message can be triggered by a NaN or infinity inside the valid footprint even when every ordinary numeric pixel appears to be in range. The earlier GEMSDOE25 site attributes one historical failure to in-footprint NaNs; that diagnosis is owner-reported, not an organizer-published validator rule.

  1. Run the file against the exact template, not just min()/max().
  2. Check the template mask: all valid cells must be finite and within [0,1].
  3. Check the outside mask separately: use null/NaN outside the footprint.
  4. Do not silently clip or rescale bad model values; fix the upstream model/output and rebuild.

Competition limits worth remembering

  • The public leaderboard is not the private test set; a public increase can be overfit.
  • The official rules allow up to three weekly platform submissions and require one selected final submission for both prize rounds. Confirm current rules and deadline before any upload.
  • The public leaderboard changes over time. DrivenData Terms of Use prohibit automated monitoring/copying, so this page uses dated snapshots rather than a scraper.
  • The 2026 homepage and rules PDF show different deadline times (11:59 p.m. UTC versus 5:00 p.m. ET); confirm the controlling cutoff with the organizer.
  • Rules require a narrative disclosure of generative-AI use if applicable. Maintain a truthful method and tool-use record for the eventual submission package; the current-session disclosure draft must be updated and entrant-approved before use.
